What this file is

An interactive reference for the HMI firmware UI. It is a port of the drawing and state logic in firmware/src/hmi_ui.c: same coordinates, colours, fonts (Montserrat weights used by src/hmi_fonts/), labels and derived states. Scenario data is illustrative, not a recorded controller session.

Source of truth

When this page and the firmware disagree, the firmware is right. The page was checked against host renders of hmi_ui.c (LVGL 9.6) for every page and scenario listed above. Glyph widths differ slightly between the browser and LVGL, so text may truncate a few pixels earlier or later than on the panel.

Not modelled

  • Backlight dimming and the 1 s refresh timer; the page renders on each click.
  • Touch scrolling details: lists scroll with the mouse wheel here.
  • Wi-Fi password entry accepts clicks on the on-screen keys only.
