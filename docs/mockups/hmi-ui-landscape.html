v2 design rules (what changed from v1 and why)

RuleReason / source
Font is Montserrat everywhere; sizes only 10 / 12 / 14 / 16 / 20 / 22 / 28 / 40 / 48 pxThese are LVGL 9.6 built-in fonts (lv_font_montserrat_N, even sizes 8–48), so the mockup renders what the panel will show. v1 used 16 sizes, 10 of them not available in LVGL.
Minimum text 12 px; 10 px only for the rail labels under an iconAbout 1.9 mm on this 3.5″ panel (~165 ppi). v1 had most text at 8–11 px.
Every text colour ≥ 4.5:1 on its backgroundWCAG 2.1 1.4.3. v1 inactive tabs and stale values were 2.6:1; future stages 1.8:1. --dim is now #86868F (4.8:1 on card).
Colour only where something is abnormal or identifies a measured channelHigh-performance HMI practice (ISA-101): normal conditions stay neutral so abnormal ones stand out. "Contact feedback: none" is a permanent property of this board, so it is grey, not a yellow warning. Header fault icon is a grey check when there is no fault.
Rings show the operating envelope: 60 V, 10 A, 600 WEnvelope from ui-pages §3.5 (≤ 60 V, ≤ 10 A continuous). Track is a dark step of the same hue (meter rule).
Stage strip: done = copper, current = boxed, future = greyThree states readable without opacity tricks.
No decorative gradient or skew on the heroNot reproducible in LVGL without cost; a pre-converted italic Montserrat 900 font gives the same look.
Touch targets: segmented tabs 40 px, page buttons 40 px, START/STOP 44 pxSpec §1.8 (about 44 × 44 px). Add lv_obj_set_ext_click_area to reach 44.
Spacing on an 8-px grid; cards 12 px radius, 12 px side paddingConsistent rhythm between pages.
Removed repeated information (Reconnect behaviour — queries only, never START/STOP — stays in the spec, not on screen)Measure: calibration and validity are already in the bit matrix and the channel chips. Faults: one compact card when nothing is active.
Pages may scroll (thumb on the right) when a banner and the action bar are both shownAllowed by spec §2 for every page except Overview.

Glyphs the built-in LVGL fonts do not have

LVGL's built-in Montserrat holds ASCII, ° and • plus the LV_SYMBOL icons only. The UI text uses · (U+00B7), — (U+2014), … (U+2026), − (U+2212) and ≤ (U+2264); the spec itself asks for "—" on missing data. Generate the 12/14/16/20/22/28 px fonts with lv_font_conv from Montserrat with the range 0x20-0x7E,0xB0,0xB7,0x2014,0x2022,0x2026,0x2212,0x2264 (4 bpp) together with the italic hero font. The "→" in event details is drawn with LV_SYMBOL_RIGHT (chevron), which the built-in symbol set already has.

Known trade-off

STOP orange-red (#E8553A) and fault pink (#FF4D7A) are close (OKLab ΔE ≈ 9, below the 15 the dataviz validator asks for). Both always carry text and an icon, so they are never told apart by colour alone. If you want them clearly distinct, shift fault towards magenta or STOP towards orange.
